Compound evidence scope & restrictions

(3′S)-(E)-7-hydroxy-5-methoxy-4-methyl-6-(2-(2-methyl-5-oxotetrahydrofuran-2-yl)vinyl)isobenzofuran-1(3H)-one

Analysis scope

核对芳环取代及乙烯基连接，并保留E双键、作者ECD赋值的3′S。E关系另获约16Hz偶合支持；不把其他未测身份当作独立产物。

5-hydroxy-7-methoxy-4-methylphthalide

Analysis scope

核对酚羟基、甲氧基与甲基在苯酞上的位置。无手性中心。原图OH完整保留，候选不存在识别误读的碘原子。

6-(3-carboxybutyl)-7-hydroxy-5-methoxy-4-methylphthalan-1-one

Analysis scope

核对羧酸侧链和芳环取代。原图唯一手性中心未赋值；外部名称命中含S构型条目仅作连接参考，候选不复制S。

6-(methyl 3-methylbutanoate)-7-hydroxy-5-methoxy-4-methylphthalan-1-one

Analysis scope

核对芳环取代位置、侧链及甲酯连接。作者明确称外消旋混合物；C3′手性不赋值，不选取单一R或S对映体。

7-hydroxy-6-[2-hydroxy-2-(2-methyl-5-oxotetrahydro-2-furyl)ethyl]-5-methoxy-4-methyl-1-phthalanone

Analysis scope

核对羟基侧链与完整五元内酯。两个手性中心均未赋值。近零旋光/CD不能单独证明外消旋或某个绝对构型；补充HPLC星号明确为溶剂峰。

(−)-Brevianamide C

Analysis scope

只核对原图连接、Z双键及11/17/19位的共同相对关系。三个中心属于同一个OR组；重绘的楔线是参考画法，不宣称11S、17S、19R已获绝对确认。旋光负号也不等于R/S赋值。

Brevianamide X

Analysis scope

核对完整笼状连接及作者以NOESY/ECD报告的3S、11R、17R、19R。候选已由原图独立原子/键重建核查；绝对构型按作者证据保存，没有独立重算ECD。

Brevianamide Y

Analysis scope

核对完整笼状连接及作者报告的3S、11S、17S、19R；重点比较与1不同的11/17位关系。绝对构型依据作者NOESY/ECD，不由名称或公共库单独补定。
